概要・サポート プライバシー 利用条件

プライバシー

Times エージェントは、許可済みTimesの発話を実際に取得・保存・AI処理します。利用範囲と保存内容を以下に示します。

処理対象

運営者が設定したMicrosoft TeamsのTeamおよび許可済みTimesチャンネルの投稿・返信を処理します。Microsoft側のRSC権限 ChannelMessage.Read.Group はTeam単位の権限ですが、アプリ側ではTeam ID・Channel IDの許可リストで処理対象を制限します。

保存する情報

  • Times投稿・返信の本文
  • 投稿者のMicrosoft Entra/AAD IDと表示名
  • Team / Channel / Message / Threadの識別子
  • 投稿時刻と、取得できる場合はTeams投稿URL
  • AIが抽出したTopic・Entity・Episode・関係と、その根拠となるMessage ID
  • 同じ通知を繰り返さないための通知記録

AI処理

対象Timesの発話は、話題・経験・困りごと・会話文脈などを構造化するためGoogle Cloud Vertex AI Geminiで処理します。Prompt Injectionのような明示的な命令パターンはGeminiへ送る前に遮断します。AI抽出結果はprovenance・confidence・content policyを検証した上で、通過したものだけをGoogle Cloud Storage上のTrusted Semantic Graphへ保存します。

Trusted RAGから除外する内容

宗教・宗教団体への支持・勧誘・説得・擁護、特定政党・候補者・選挙運動・投票選択への支持・反対・説得、暴力・犯罪を主題とする発話、特定個人への侮辱・非難・敵対的評価は、Raw Memoryには保持してもTrusted Semantic Graph、RAG検索、自律DMの根拠には利用しません。宗教・政党・人物についての中立的な事実言及だけで除外することはありません。

Teams DM

Times エージェントは、関連人物または最近その話題で困っていた人へ1:1 Teams DMを送ることがあります。候補者からTimes エージェントへの個人DM返信は、知識化・検索・保存の対象にしません。

利用しない情報・目的

  • 個人DM本文をGraph Memoryへ保存しません。
  • 広告配信やデータ販売を目的に利用しません。
  • 発話だけから人物の能力、性格、心理状態を断定しません。

保存期間・削除

現在のハッカソン/限定試験では、対象データは運営者が明示的に削除するか、試験環境を終了するまで保持します。自動削除期間は現在設定していません。削除・対象除外を希望する場合は問い合わせ窓口へご連絡ください。

セキュリティ

Graph MemoryはGoogle Cloud Storageに保存し、公開アクセスを禁止しています。MicrosoftアプリのCredentialはGoogle Secret Managerで管理します。Semantic Graphの関係には根拠Message IDを保持し、由来を検証します。自律DMにはKill Switch、重複抑止、送信数上限を設け、Governance Auditには投稿本文や個人IDを含めず判断理由だけを記録します。
